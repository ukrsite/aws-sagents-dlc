# Units of Work

## Unit 1: User Authentication Service

This unit handles user authentication logic including login, logout, and session management.

**Responsibilities:**
- User credential validation
- Session token generation
- Login/logout endpoints

## Unit 2: User Profile Service

This unit manages user profile data including CRUD operations for user information.

**Responsibilities:**
- Profile data storage
- Profile update endpoints
- Profile retrieval endpoints

## Unit 3: User Notification Service

This unit handles sending notifications to users via email or SMS.

**Responsibilities:**
- Email notification dispatch
- SMS notification dispatch
- Notification template management
